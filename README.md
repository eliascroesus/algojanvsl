## Uploading

**Videos (up to 2 GB each):** these go in a GitHub Release, which takes big files straight from the browser.
There's one release per folder. Open its link (if GitHub asks about the tag, pick **Create new tag … on publish**),
drag the videos into the box at the bottom ("Attach binaries"), wait until every file has finished uploading,
then click **Publish release**:

| Videos | Upload link |
| --- | --- |
| **Raw VSL** | [releases/new?tag=raw-vsl](https://github.com/eliascroesus/algojanvsl/releases/new?tag=raw-vsl&title=Raw%20VSL) |
| **Thank-you raw footage** | [releases/new?tag=thank-you](https://github.com/eliascroesus/algojanvsl/releases/new?tag=thank-you&title=Thank-you%20raw%20footage) |
| **FAQ raw footage** | [releases/new?tag=faq](https://github.com/eliascroesus/algojanvsl/releases/new?tag=faq&title=FAQ%20raw%20footage) |
| VSL reference | [releases/new?tag=vsl-reference](https://github.com/eliascroesus/algojanvsl/releases/new?tag=vsl-reference&title=VSL%20reference) |
| Thank-you reference | [releases/new?tag=thank-you-reference](https://github.com/eliascroesus/algojanvsl/releases/new?tag=thank-you-reference&title=Thank-you%20reference) |
| **Results and images** (student results, photos of Jan) | [releases/new?tag=results-and-images](https://github.com/eliascroesus/algojanvsl/releases/new?tag=results-and-images&title=Results%20and%20images) |

**Pictures, screenshots and small files (under 25 MB):** open the folder on GitHub, click
**Add file → Upload files**, drag the files in and click **Commit changes**.

To add more videos to a release later, open it under **Releases**, click the pencil (Edit), attach the
files and click **Update release**. Files over 2 GB need to be split or exported smaller first.
