# Results and images

Pictures for the edits: **student results** (payout certificates, P&L screenshots, testimonials, Discord messages),
**photos of Jan**, lifestyle shots, logos, and any other images or short B-roll clips.

**Upload here (as many files as you like, up to 2 GB each):**
[Results and images release](https://github.com/eliascroesus/algojanvsl/releases/new?tag=results-and-images&title=Results%20and%20images)

1. Open the link. If GitHub asks about the tag, pick **Create new tag: results-and-images on publish**.
2. Drag the images into the box at the bottom ("Attach binaries by dropping them here"). You can drop a whole
   batch at once, or a `.zip` of a folder.
3. Wait until every upload bar has finished, then click **Publish release**.

Tips:
- Name files so they're easy to place, e.g. `result-ali-12k-payout.png`, `jan-desk.jpg`, `testimonial-sarah.mp4`.
- Upload the original, full-size files (not WhatsApp-compressed copies) so they stay sharp at 1440p.
- If something needs context (who it is, what the number means, if it must be blurred), add a line about it
  in the release description or in a `notes.md` here.

To add more files later, open the release under **Releases**, click the pencil (Edit), attach the files and click
**Update release**.
