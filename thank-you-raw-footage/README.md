# Thank-you video: raw footage

Jan's raw, unedited thank-you video (the one people see after they apply / book a call).

**Upload here (up to 2 GB per file):**
[Thank-you raw footage release](https://github.com/eliascroesus/algojanvsl/releases/new?tag=thank-you&title=Thank-you%20raw%20footage)

1. Open the link. If GitHub asks about the tag, pick **Create new tag: thank-you on publish**.
2. Drag the videos into the box at the bottom ("Attach binaries by dropping them here").
3. Wait until every upload bar has finished, then click **Publish release**.

If it was recorded in several takes or with separate audio, upload every file and note the order in a
`notes.md` here.

**Small files (under 25 MB)**, e.g. a script, notes or extra pictures:
[upload to this folder](https://github.com/eliascroesus/algojanvsl/upload/claude/awesome-cray-94qf0w/thank-you-raw-footage).

To add more files later, open the release under **Releases**, click the pencil (Edit), attach the files and click
**Update release**. Files over 2 GB need to be split or exported smaller first.
